📚 Bedrock Canary Cheatsheet & Syntax Reference

1. State Declaration

Declare reactive variables easily:

State score = 0
State username = "Alex"

2. Event Actions

Mutate state or change screens:

Action addScore {
  set score = score + 10
}

3. Screen Layouts

Combine Stack, Row, Card and Buttons:

Screen MainScreen("Dashboard") {
  Card {
    Text("Points: {score}")
    Button("+ Add") on click => addScore
  }
}
